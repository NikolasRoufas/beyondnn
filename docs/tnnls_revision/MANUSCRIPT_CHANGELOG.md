### B. Draft and revision-process language removed

All ten passages listed in MANUSCRIPT_CONSISTENCY §3 are gone: "the draft", "this revision", "source bundle", "checkout", "supplied aggregate table", and "the manuscript's Wilson intervals".

### C. New scientific content

1. **Formal framework** (new §III):
   - definitions of evidence record, provenance, claim, necessity test with the attainability condition, configuration and role, admissibility, and standing;
   - six propositions (admissibility, role invariance, monotone reversal count, threshold asymmetry, provenance refusal, re-derivability). Each is stated as holding by construction and linked to the enforcing code and to a test or experiment.
2. **RQ1 decomposition** (§VI-A, Table III, Fig. 3): fixed-selection versus subject-changing reversals, from an exact re-execution of the frozen design (0 per-sample differences).
3. **RQ3 comparison with conventional workflows** (§VI-C, Table IV): seven injected faults on identical measurements; B0, B1 and BeyondNN. This includes the negative result that a careful checker matches the audit's detections.
4. **RQ4 reference labels** (§VI-D, Fig. 4): the InterpBench re-analysis against specification labels on trained transformers is added. The Tracr results are retained with corrected wording.
5. **RQ6 checkpoint replication** (§VI-F, Table V, Fig. 5): five seeds each for the MLP and CNN.
6. **RQ7 re-execution and cost** (§VI-G, Table VI, Fig. 6):
   - cross-platform re-execution;
   - reload and re-audit identity;
   - per-phase cost;
   - a per-test overhead against plain PyTorch.
7. **Capability table** (Table I), with Certified Circuits and Lin & Liu added to the related work.
8. **Acknowledgment** with an AI-assistance disclosure, following the IEEE guidelines. It is marked for author review.
